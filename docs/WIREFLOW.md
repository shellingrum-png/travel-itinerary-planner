# 页面流程与交互设计

> 对应 PRD V3.0,反映实际实现。

## 1. 页面清单(8 页)

| 页面 | 路径 | 说明 |
| :--- | :--- | :--- |
| 旅程列表 | `/` | 我的旅程卡片列表,新建/删除/导入 |
| 旅程详情 | `/trip/:id` | 天数 Tab,预算条,搜索/地图/全局优化入口 |
| 单日时间轴 | `/trip/:id/day/:n` | 核心编辑页:排点+通勤+优化+冲突 |
| 景点检索 | `/trip/:id/search` | 高德 Web API 检索,结果+地图联动,暂存箱 |
| 景点详情 | `/trip/:id/poi?poiId=...` | POI 详情 + AI 卡片(5 层读取链) |
| 地图总览 | `/trip/:id/map` | Leaflet 暗色全屏地图,按天着色,天卡片联动 |
| 记账 | `/trip/:id/bookkeeping` | 消费列表,预算条,人均,分摊账单 |
| 暂存箱 | 嵌入 DayTimeline 和 PoiSearch | 跨页面共享(zustand stagedStore) |

## 2. 页面交互流程

```
首页(/)

  ├─ 新建旅程 ──▶ 填标题/目的地/日期 → 自动生成天数
  │
  ├─ 导入青甘大环线 ──▶ 一键创建 10 天 20+ 景点(含坐标)
  │
  └─ 点击旅程卡片 ──▶ 旅程详情(/trip/:id)
                          │
          ┌───────────────┼───────────────────┐
          ▼               ▼                   ▼
    搜索景点          日程序列表          记账(/trip/:id/bookkeeping)

      │                  │                   · 预算条(已花/剩余/人均)
      │ 检索 POI         │ 点击某天            · 分摊账单(差额结清)
      │ 结果+地图联动     │
      │ 加入暂存箱 ──────┼──▶ 单日时间轴(/trip/:id/day/:n)
```

## 3. 关键状态机

### 3.1 旅程状态
```
planning ──[手动]──▶ ongoing ──[手动]──▶ finished
    │                                      │
    └────────[可回到 planning 编辑]──────────┘
```

### 3.2 排点交互(单日)
```
暂存箱 ──点击──▶ Day(insert order_seq=末尾,自动 upsertPoi)
手动添加 ──▶ Day(填名称,item_type=poi/buffer)
改游览时长 ──▶ 更新 visit_minutes → 级联重算时间
改出行方式 ──▶ fetch amap.getDuration → 回填 arrive/leave → 冲突检测
一键优化 ──▶ solveTsp → 预览节省分钟 → [确认新顺序/取消]
确认优化 ──▶ 回写 order_seq → 撤销按钮激活
撤销 ──▶ 恢复优化前顺序(单层快照)
```

### 3.3 冲突预警生命周期
```
触发(规则命中) ──▶ ⚠️ 黄标(可展开看原因+建议)
  ├── 用户调整(时间/方式/删点) ──▶ 重算 → 消除
  └── 用户忽略 ──▶ 持续黄标(不强拦)
预算超额 ──▶ 顶部红条 + 红标(不阻断记账)
```

### 3.4 AI 卡片 5 层读取链
```
请求卡片(poi, city)
  │
  ├─ 1. RAG 攻略库(best-effort) → 未配置/为空 → 静默跳过
  ├─ 2. poi_ai_cards 缓存命中 → 返回(0 API 调用)
  ├─ 3. LLM 生成(DeepSeek) → 成功 → 写缓存 → 返回
  ├─ 4. 类型兜底(景点90/餐厅60/购物45/未知90) → 写缓存
  └─ 5. 用户手动覆盖(UI 层锁定,不被上述层覆盖)
```

## 4. 关键业务规则

- **自动生成天数**: 建旅程时自动生成 `itinerary_days`(day_seq=1..N)
- **Day 边界推导**: `start_time` = 手动覆盖 > 酒店 check_in > 前日交通 arrive_at 次日 09:00 > 默认 09:00;`end_time` = 手动覆盖 > 酒店 check_out > 当日交通 depart_at > 默认 20:00
- **时间级联**: `下一节点到达 = 上一节点离开 + 通勤时间`,支持跨午夜 24h+ 记号
- **TSP 优化**: n≤8 Held-Karp 精确解,n>8 2-opt 近似;单层快照撤销
- **通勤过紧**: 留白 < 15min 触发预警(含等号不触发)
- **缓存策略**: POI 检索 7 天,路径 30 天,AI 卡片永久;md5 幂等
- **暂存箱**: 跨页面共享(zustand),按 trip_id 隔离
- **记账校验**: 0<金额≤999999,最多两位小数,分类必选
- **离线**: 弱网提示条,IndexedDB 本地全量,地图 Leaflet CDN 瓦片
- **数据导入**: Excel → seed JSON → 一键创建旅程(含真实坐标)
- **Seed 脚本**: `scripts/seed.cjs` 解析 Excel,输出 JSON 到 `src/frontend/seed.json`
