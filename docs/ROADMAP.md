# 开发路线图(MVP 里程碑)

> 个人单干,建议每周一个可运行的交付物。每个里程碑都有**退出标准**,满足后再进下一阶段。

## 排期总览

| 阶段 | 周期 | 交付物 | 退出标准(验收) |
| :--- | :--- | :--- | :--- |
| **M0 脚手架** | W1 | 项目骨架 + Dexie 表 + 三页可跑 | `trips` 列表可建旅程、自动生成天数骨架 |
| **M1 纯文本时间轴** | W2 | 手动文字排点 + 时间轴渲染 | 无地图可完整做 1 天行程(纯文本可用) |
| **M2 地图接入** | W3 | 高德地图、POI 检索打点、景点详情、暂存箱 | 检索"塔尔寺"→ 打点 → 拖入 Day 2;**孤儿节点自动删除+提示**生效 |
| **M3 路径计算** | W4 | 出行方式 → 通勤时间自动回填 | 时间级联正确、`route_cache` 生效(无重复计费) |
| **M4 顺路优化 + 预警** | W5 | 一键重排 + 冲突预警 | 重排提示节省分钟;**边界测试(留白15min→无预警 / 14min→有预警)**通过;优化后撤销只回退最近一次 |
| **M5 AI 卡片** | W6 | LLM 生成推荐卡片 + 缓存 | 二次查询 0 API 调用;断网可读卡片 |
| **M6 记账 + 打磨** | W7 | 记账、预算、人均、离线同步 | 全文 §7.2 的 9 个冒烟用例全部通过 |
| **M7 地图总览** | W8 | 高德暗色全屏地图,按天着色 Marker+路线 | Marker+Polyline+跨天连线,天卡片联动 |
| **M8 数据导入** | W9 | seed JSON 一键导入 | 青甘大环线 10 天 20+ 景点一键创建 |
| **M9 一站式地图编辑** | W10 | 左侧天卡片+右侧地图,景点/酒店/交通直接搜索添加 | 搜索→选点→地图预览→确认添加,全流程不跳转 |

> 若总用时目标 < 6 周:M5 先降级为「纯本地模板库」(`poi_ai_cards.content_json` 预填一批热门模板),AI 卡片后补。

## 冒烟测试清单(最终验收)

1. 新建「青海国庆 7 日」旅程,设预算 8000 元、2 人;
2. 进入**一站式地图编辑页**,点击 Day 2 展开景点 Tab;
3. 搜索「塔尔寺」→ 选中候选 → 地图飞移到该点 → AI 卡片生成 → 确认添加到 Day 2;
4. 酒店 Tab 搜索酒店 → 确认添加;
5. 交通 Tab 输入起点/终点 → 查询路线 → 确认添加;
6. 时间轴上自动出现新节点,通勤时间级联刷新;
7. 一键顺路优化,看到节省提示;再优化一次后撤销,验证只回退最近一次;
8. 途中断网,仍可查看 Day 2 时间轴;
9. 记录餐饮 200 元,预算条实时变化(金额输 -50 应被拦截);
10. 点击景点名称进入详情页,LLM 卡片已缓存,无二次 API 调用;
11. RAG 未配置(空知识库)时,整个流程无感知。
